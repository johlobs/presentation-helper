Plan the order and content of a talk

Open a PowerPoint file to group the slides, set a time budget, decide what to keep or cut, edit titles and slide text, and work on the speaker notes (by typing, dictating or translating). Save & update pptx writes the new order, sections, hidden slides and notes back into the file, and Download pptx gives you the updated file as a new copy with its own name. Your original file is never changed.

Everything stays in this browser. The file is read and rewritten on your computer and is never uploaded. Dictation runs a speech model locally as well. The only exception is translation, which sends the text you translate to Google Translate and MyMemory.
